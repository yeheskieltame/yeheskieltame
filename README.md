## 🚀 Featured Ecosystem

### 1. 🌾 OwnaFarm (Agricultural RWA + GameFi)
**Bridging the $170B Agricultural Finance Gap on Mantle L2.**
* **The Use Case:** Transforms agricultural invoice financing into a "Plant-to-Earn" simulation. Farmers get fast working capital, while investors earn real yield (15% APR) by "planting seeds" and "watering" their portfolio.
* **Technical Stack:** Invoices tokenized as **ERC-1155**, built with **Solidity (Foundry)** and **Go (Gin)** for the backend.
* **Links:** [Live App](https://ownafarm-farmer.vercel.app/) | [Demo Video](https://youtu.be/D8RmfS-OOtw)

### 2. 🏠 Owna Finance (Real Estate Tokenization)
**Democratizing Property Investment on Base.**
* **The Use Case:** Fractionalizes high-value real estate assets in Indonesia. Retail investors can start investing with as little as $1, receiving automated yield distributions from rental income.
* **Technical Stack:** On-chain ownership records and automated distribution logic on **Base Blockchain**.
* **Links:** [Live App](https://ownafinance.xyz) | [Docs](https://owna-finance.gitbook.io/owna-finance-docs)

### 3. 📐 OneTriangle (Gamified Savings)
**DeFi Protocol that Gamifies Stablecoin Savings.**
* **The Use Case:** A "No-Loss" protocol for USDC. Users deposit savings and join a faction. The collective yield is won by the winning faction, while everyone's principal remains 100% protected and withdrawable.
* **Technical Stack:** DeFi yield-aggregator integration with a gamified winner-take-all prize pool.
* **Links:** [Live App](https://onetrianggle.vercel.app/)

### 4. 🛡️ OneSafeBet (No-Loss Prediction Market)
**Capital-Protected Gaming on Hedera.**
* **The Use Case:** Eliminates the financial risk of traditional prediction markets. Using the principle: *"Your money stays yours. Only the interest fights,"* it uses native staking rewards as the reward pool.
* **Technical Stack:** Native **Hedera Staking** integration and smart contract-based vault system.
* **Links:** [Live App](https://onesafebet.vercel.app/)
