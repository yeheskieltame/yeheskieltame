## 🌐 Multi-Chain Ecosystem

### 🌾 OwnaFarm — Built on **Mantle**
**🏆 1st Place Winner - Mantle Global Hackathon 2025 (GameFi Track)**
* **Business Case:** Bridging the $170B agricultural financing gap. It transforms invoice financing into a "Plant-to-Earn" simulation. Farmers gain access to capital without traditional collateral, while investors earn real yield.
* **Technical Edge:** Real-time crop monitoring via **Integrated IoT/CCTV** and invoice tokenization using **ERC-1155** on Mantle L2.
* **Links:** [Live App](https://ownafarm-farmer.vercel.app/) | [Demo Video](https://youtu.be/D8RmfS-OOtw)

### 🛡️ OneSafeBet — Built on **Hedera**
**🏆 Top 3 - Hedera Hello Future Ascension 2025 (DeFi Track)**
* **Business Case:** A "Capital-Protected" prediction market. By using the principle: *"Your money stays yours. Only the interest fights,"* it eliminates financial risk—your principal is 100% protected.
* **Technical Edge:** Native **Hedera Staking** integration. Funds are managed in non-custodial vaults, converting generated yield into **"Battle Power"**.
* **Links:** [Live App](https://onesafebet.vercel.app/)

### 🏠 Owna Finance — Built on **Base**
**Real Estate Fractionalization & RWA**
* **Business Case:** Democratizing property investment in Indonesia. Retail investors can own fractions of high-value assets starting from $1, receiving automated rental yield distributions on-chain.
* **Technical Edge:** Automated distribution logic and transparent ownership records built on **Base**.
* **Links:** [Live App](https://ownafinance.xyz)

### 📐 OneTriangle — Built on **Onechain**
**🏆 3rd Place Winner - OneHack 2.0**
* **Business Case:** A gamified "No-Loss" savings protocol. Users deposit funds into factions; the collective yield is won by the winning group, while all participants can withdraw 100% of their principal.
* **Links:** [Live App](https://onetrianggle.vercel.app/)
